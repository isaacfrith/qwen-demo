# Databricks DBT Repository

This repository contains a metadata-driven DBT project for silver and gold layer transformations in Databricks.

## Structure
- `dbt_project/` - Main DBT project with silver/gold models
- `src/` - Source code for API/JDBC connectors and metadata framework
- `configs/` - Configuration files for different environments

## Features
- Metadata-driven transformation framework
- Core API and JDBC connectors
- Silver and gold layer transformations
- Environment-specific configurations
